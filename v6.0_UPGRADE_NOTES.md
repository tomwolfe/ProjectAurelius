# Project Aurelius v6.0 Upgrade Notes

## Overview

Project Aurelius v6.0 introduces five major architectural improvements while maintaining full backward compatibility with v5.2. All existing CLI flags, config schemas, and public APIs remain functional.

## Breaking Changes

### 1. RDKit is Strictly Required for Real Model Screening

**Before (v5.2):**
```bash
# Would proceed with hash-based fallback if RDKit missing
aurelius screen "CC(=O)OC1=CC(=O)O1"
```

**After (v6.0):**
```bash
# Raises RuntimeError if RDKit is not installed
aurelius screen "CC(=O)OC1=CC(=O)O1"

# Install RDKit to use real models
pip install rdkit

# Or use hash fallback for demo/CI
aurelius screen "CC(=O)OC1=CC(=O)O1" --allow-fallback

# Or use demo mode (no RDKit needed)
aurelius screen "CC(=O)OC1=CC(=O)O1" --demo
```

**Migration:**
- Ensure RDKit is installed: `pip install rdkit`
- For CI environments without RDKit, add `--allow-fallback` to all `screen` and `batch` commands
- For demo runs, use `--demo` flag which disables real models entirely

### 2. Version Number Bump

**Before:** `5.2.0`
**After:** `6.0.0`

Update any version-dependent code:
```python
# Before
assert aurelius.__version__ == "5.2.0"

# After
assert aurelius.__version__ == "6.0.0"
```

> **Note:** `aurelius.__version__` attribute does not exist in the package. Check version via CLI:
> ```bash
> aurelius --version
> ```

## New Features

### Task 1: MPNN Activation Energy Predictor

**New module:** `src/aurelius/screening/tier0_gnn.py`

**New CLI command:**
```bash
aurelius train --task tier0 --epochs 200
```

**Usage in code:**
```python
from aurelius import Tier0ActivationPredictor, GCMDigitalTwin

# Load with MPNN (if weights exist) or fallback to linear model
predictor = Tier0ActivationPredictor(model_path="models/tier0/mpnn_weights.pth")
energies = predictor.predict(smiles="CC(=O)OC1=CC(=O)O1")

# In pipeline (auto-loaded when use_real_models=True)
pipeline = AureliusPipeline(config, use_real_models=True)
```

**Training data:**
- Generated at `data/train_tier0_synthetic.csv` (500 rows)
- Model weights saved to `models/tier0/mpnn_weights.pth`

### Task 2: Cutoff-Aware Neighbor Lists

**New config options:**
```python
config = M5ProConfig(
    use_neighbor_list=True,       # Enable neighbor list
    neighbor_list_cutoff=14.0,    # Cutoff radius in Angstroms
)
```

**Performance:**
- O(N²) → O(N·M) for N > 50 atoms
- Dense path preserved for N < 50 (MPS throughput optimization)
- Matches O(N²) energies within 1e-6 tolerance

### Task 4: HuggingFace Hub Upload

**New CLI command:**
```bash
aurelius hf-upload \
  --model-dir models/tier0 \
  --repo-id myuser/aurelius-tier0 \
  --task tier0 \
  --private \
  --commit-message "Add trained MPNN model"

# Dry run to validate
aurelius hf-upload \
  --model-dir models/tier0 \
  --repo-id myuser/aurelius-tier0 \
  --dry-run
```

**Requirements:**
- Set `HF_TOKEN` environment variable or run `huggingface-cli login`
- `huggingface-hub` is already a core dependency

### Task 5: Memory Profiler

**New module:** `src/aurelius/memory/profiler.py`

**Usage in code:**
```python
from aurelius import MemoryProfiler

profiler = MemoryProfiler(output_dir="outputs/")
profiler.start()
# ... screening loop ...
profiler.sample(generation=1, screened_count=50, gc_collected=3)
profiler.stop()
csv_path = profiler.generate_report()
# Output: outputs/memory_profile_20260516_123456.csv
```

**Agent CLI flag:**
```bash
python autonomous_screening_agent.py --profile-memory
```

**CSV columns:**
| Column | Description |
|--------|-------------|
| generation | Current generation number |
| screened_count | Total molecules screened |
| current_ram_gb | Current RSS memory |
| peak_ram_gb | Peak RSS memory |
| mps_cached_gb | Current MPS allocated memory |
| peak_mps_gb | Peak MPS memory |
| mlx_cached_gb | Current MLX Metal memory |
| peak_mlx_gb | Peak MLX memory |
| gc_collected | Objects collected by gc.collect() |
| elapsed_s | Seconds since profiling started |

## Deprecation Timeline

| Component | Deprecation | Removal | Action Required |
|-----------|------------|---------|-----------------|
| Hash fallbacks in real mode | v6.0 | v7.0 | Use `--allow-fallback` for demo/CI |
| `Tier0ActivationPredictor` linear-only | v6.0 | v7.0 | Migrate to `Tier0ActivationPredictor(model_path=...)` |
